# AI Agency Commands

## Command Format

Use:

@agency <your request>

## Examples

@agency create a lead generation automation for a gym

@agency create WhatsApp follow-up automation for a real estate business

@agency create an appointment booking automation for a salon

@agency create a client proposal for a restaurant automation

## Agency Workflow

1. Read the user's command.
2. Understand the business requirement.
3. Identify the required automation.
4. Create the workflow plan.
5. Create client-facing messages.
6. Create a proposal.
7. Create implementation instructions.
8. Report the completed work.
